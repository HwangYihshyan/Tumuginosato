概要糸で、霧に呑まれた村を紡ぎなおす

霧に呑まれ、思い出ごと消えかけた機織りの村「ハタオリ村」。主人公ソラと糸の妖精ツムギは、地下の迷宮「根の洞」に潜り、 糸巻きの形になって散らばった村のかけら（ジオラマパーツ）を集めて持ち帰ります。 持ち帰ったジオラマを村に置き、小さなパーツをはめ込んで建物を完成させると、店や鍛冶屋が開き、仲間が加わり、もっと深い階へ挑めるようになります。

ゲームの流れ

根の洞潜る全15階。戦って、糸巻きを開ける
›
根の洞持ち帰る各階10個の糸巻きからジオラマパーツ
›
村置く・はめるマスに置き、枠にパーツをはめ込む
›
村よみがえる機能・仲間・イベントが解放され、次の階へ

形は「基本図形 ＋ 手続き生成」

球・円柱・円錐などの基本図形をコードで生成し、行列で組み合わせてキャラクターや建物を描いています。主人公の武器「大糸切り鋏」の刃は、刃の幅・厚み・刃先の反りを関数で決めてメッシュを手続き生成しました。

3D と 2D を一枚の絵に

3D を MSAA で描いて解決したあと、同じバックバッファに Direct2D で UI と日本語の文字を重ねています。配置メニューのサムネイルは、部品の3D模型をオフスクリーンのアトラスに一度だけ描き、2D の UI に貼る仕組みです。

光とライトの管理

宝箱・泉・灯などの点光源は毎フレーム集め、カメラの注視点に近い順に16個までをシェーダへ渡します。灯（ランタン）の残量でフォグの距離と自分の明かりが変わり、探索の緊張感につながっています。

自動撮影による動作確認

--autoshot で起動すると、台本どおりにゲームを自動で進め、約90場面のスクリーンショットと確認ログを書き出します。村づくり・15階の攻略・QTE・メニュー操作までを毎回同じ条件で確かめられるため、修正による不具合（デグレード）にすぐ気づけます。

POINT 2アニメ調のトゥーンシェーディング

HLSL で自作したシェーダー1本で、絵本のような柔らかさと、くっきりしたアニメの塗りを両立させました。

3段階の陰影 ＋ 影の色

光の当たり具合を smoothstep でほぼ段差にし、「影・中間・明るい」の3段に分けています。影はただ暗くするのではなく、場面ごとに決めた色（洞は青紫、村は霧の青から夕焼けの紫へ）に寄せ、アニメの塗りらしさを出しました。

背面法の輪郭線

裏面だけをもう一度、法線方向にふくらませて描き、墨のような輪郭線にしています。カメラから遠いほど少し太くして画面上の太さをそろえ、霧の中でも線が消えすぎないよう調整しました。

法線のゆがみの修正

キャラクターは縦横の倍率が違う球を多く使うため、法線を world 行列で変換すると影の境目がずれます。逆転置行列で変換するよう直し、どの形でも陰影が正しく出るようにしました。

金属のハイライトとリムライト

ハーフベクトルを使ったハイライトを smoothstep で「くっきりした光の点」にし、鋏の刃や針だけに乗せています。輪郭のリムライト・点光源・高さのある霧と合わせて、暗い洞でも形が読み取れます。

POINT 3遊びの幅を広げるアクションとダンジョン

3人の仲間はそれぞれ「攻撃・右クリックの技・回避」がまったく違い、階ごとに戦い方が変わるよう設計しました。

15階
深い階ほど新しい敵が混ざる。3・7・14階は操作キャラ固定
3人
ソラ（近接）・クロベエ（範囲と防御）・カイリ（遠距離）を Tab で交代
8種
正面の攻撃を受け流す鎧武者など行動の違う敵6種と、ボス2体（ほつれ蜘蛛・うつろ）

キャラクターごとの手ざわり

ソラ：巨大な糸切り鋏で「開く→挟む→振り抜く」3段コンボと、刃を開いて回る溜め攻撃。クロベエ：ひも通しを扇形に薙ぎ払い、紐を回して飛び道具を防ぎ、地面に潜って回避。カイリ：ミシン針を投げ、溜めると敵を貫く大針。

15階のボス「うつろ」：地形を使う戦い

4本の糸の柱が残っているあいだ攻撃が効きません。柱は攻撃でも壊せますが、うつろの突進を柱の前へ誘い込んでぶつけさせると柱が砕け、うつろが目を回します。18秒たつか体力が1/4減ると柱が紡ぎなおされるため、攻めどきを見極める駆け引きが生まれます。

12階の QTE

回避・連打・ツムギの糸での縫い留め・とどめの4つの合図。刺繍枠の縫い目がほどけていく表示で残り時間を伝えます。

POINT 4集めたものが形になる、ジオラマの村づくり

ダンジョンの成果が「目に見える村の変化」として返ってくることで、もう一度潜りたくなる循環を作りました。

置く ― 地形のルールがあるパズル

20×20 マスの村に建物・道・木を置きます。水車と橋は川の上だけ、井戸は川から2マス以内。橋をかけると向こう岸へ渡れて、そこにも置けるようになります。並べた川は水がつながり、橋を並べると幅広の1本の橋になります。

はめる ― 枠の形でわかるはめ込み

建物には「はめ込み枠」があり、暖簾・看板・住人などのパーツを、灰色の影絵で示した同じ形の枠へ運んではめます。人物をはめるとその人が住人として町を歩きはじめます。

話す ― 住人が村づくりを手伝う

住人との会話は「物語・ジオラマ・村・コツ」の話題から選びます。はめ込みの解放、足りないパーツの手がかり、復興率の上昇につながり、会話そのものが進行の手段になっています。

完成 ― 機能と仲間の解放

枠が全部うまった建物のそばへ行くとイベントが起き、店・鍛冶屋・機織り小屋が使えるようになり、炭焼き窯ではクロベエ、水車ではカイリが仲間に加わります。

配置／組み立てメニュー。右の欄のパーツを、左のカードの同じ形の枠へ運ぶ
川と橋、石垣で囲んだ村の範囲

POINT 5世界観から作った「和紙と墨と糸」の UI

よくある四角いパネルではなく、機織りの村という題材から形と色を決め、すべての画面で同じ部品を使いました。

共通の部品で統一感を出す

墨の板・和紙の札・朱のタブ・斜めのゲージといった UI の部品を関数にまとめ、色は「墨・和紙・朱・金」の4つに絞りました。部品を変えれば全画面に反映されます。角を斜めに切った形や縫い目の点線は、Direct2D のパスを使って描いています。

糸のモチーフを情報の表現に

  • 会話：和紙の札を赤い糸で縫った枠。「次へ」は糸のついた針
  • 復興率：織りかけの反物。復興が進むほど布が織りあがる
  • お金：赤い紐に通した穴あき銭（銭差し）
  • 村のメニュー：縦糸に通した糸巻きが項目。選ぶと糸が巻物へつながる
  • QTE の残り時間：刺繍枠の縫い目がほどけていく

戦闘中は読みやすさを優先

ダンジョンの HUD は大きな顔と斜めのゲージのアニメ調にし、受けたダメージを白い帯が遅れて追いかける表現で伝えます。ボスの体力や柱のゲージは、ほかの表示と重ならない位置に自動で収めています。

エンジンの中で何が起きているかを理解した

定数バッファの並び（16 バイト境界）、行列の行優先・列優先、法線の変換、深度とブレンドの状態管理など、エンジンが隠している部分を自分で書いたことで、描画の問題を原因から説明して直せるようになりました。

遊びと見た目を、題材から一貫させる

「糸で村を紡ぎなおす」という題材を、ゲームの仕組み（糸巻き・はめ込み）、ボス戦（糸の柱）、UI（縫い目・反物・刺繍枠）まで通しました。コンセプトから逆算して設計する考え方を身につけました。

確かめられる作り方

自動撮影の台本で、約90場面とログを毎回同じ条件で出力し、修正のたびに見比べて不具合を早く見つけました。
