# ツムギノサト ― 霧海の記憶 ―（垂直スライス）

C++17 / DirectX 11 / HLSL。企画書 第2版をもとにした第1章の試作です。
テクスチャは KageNui_Textures から必要なものだけ `Assets/Textures` にコピーしています。

## ビルドと起動
```
build.bat                      … bin\TsumugiNoSato.exe ができる
bin\TsumugiNoSato.exe          … 通常プレイ
bin\TsumugiNoSato.exe --autoshot Screenshots   … 自動デモを流してプレイ画面を87枚保存して終了（確認結果は *_test.txt・dungeon_test.txt・village_test.txt）
```

## ゲームの流れ
1. 「はじめから」：霧の村で目覚める。残っているのは**村長トウジと村長の家だけ**。ほかのジオラマは全部、根の洞の糸巻きから手に入れる
2. 村長に話しかけて話題「ジオラマのこと」を選ぶと、**はめ込みが解放**される
3. 北の鳥居の奥の入口で E → 入る階を選ぶ（行ったことのある階まで）→ 歩いて入り、暗転して題字 → 降り立つ
4. ダンジョンは**全15階**の広いマップ（44×44マス・部屋が最大12）。ふつうの階は入ると**糸巻きが10個**、あちこちの部屋に出る（1つにパーツ1つ）。**ボスの階（5・15）と QTE の階（12）には宝箱も糸巻きも出ない**
   - 赤い宝箱：アイテム・アタッチメント・お金／黒い大きな宝箱：新しい武器
5. 村に戻り、Tab（または Esc のメニュー →「ジオラマ配置」）で**配置**
6. 置いた建物のはめ込みは、**住人に「ジオラマのこと」を聞くと解放**（話しかけた住人が手伝ってくれる）。**人物のパーツは最初からはめられる**
7. 配置メニューで、右の欄のはめ込みパーツを持ち上げ（Enter かクリック）、**左の建物のカードの同じ形の枠へ運んで**はめる（Enter か、クリック／ドラッグして離す）。枠ははめるパーツが決まっていて、**置く前のカードも置いたあとのカードも、どの建物でもそのパーツの形が灰色の影絵で見える**（解放前は「未解放：住人と話す」と出る）。はめると色がつく。形の違う枠には入らない
8. はめ込み枠が全部うまると**完成**し、カードに「イベント！」が出る（完成する前は出ない）。町で完成した建物のそばへ行くと**イベント**が起き、機能や仲間が解放される
   - 商人の店 → 店が開く（買い物）／鍛冶屋 → 武器をまとめて修理（40文）／機織り小屋 → ほつれ糸3本でアタッチメント
   - 炭焼き窯 → イベントのあと**クロベエが仲間に**（2階で一式そろう）／水車に「カイリ」（12階の QTE のあとに出る糸巻き）をはめて完成 → イベントのあと**カイリが仲間に**
9. 121個のパーツを全部置いて、はめ込みもすべて終えると、**御神木の前でイベント**（村の完成・第1章おしまい）

## 仕様
| 項目 | 内容 |
|---|---|
| はめ込み | 家・工房・店・炭焼き窯（枠3つ）、水車・畑（枠1つ）。井戸ははめ込みなし。枠ごとにはめるパーツが決まっている（例：商人の店＝タヌキの商人・看板・酒樽、炭焼き窯＝薪の束・薪の束・軒提灯）。はめ込みパーツは暖簾・軒提灯・植木鉢・酒樽・薪の束・看板と、**人物**（村長・タヌキの商人・機織りの娘・鍛冶屋の親方・ウサギの姉妹・里人・里の子ども）。人物のジオラマは**みんなだるま型**で、**最初からはめられる**。**人物ははめ込むと住人として町に現れる**（はめ込む前は出てこない）。パーツの数は枠の数とちょうど同じ（29。余っていた酒樽2つは、4階・8階で川に変えた） |
| 川と橋・井戸・水車 | 川は村の**まん中**（14・15列）を流れ、その東は「向こう岸」。**橋をかけると向こう岸へ渡れて、そこにも置ける**。「橋」「水車」は**川の上にだけ**、「井戸」は**川から2マス以内**にだけ置ける。「川」は1マスの小川として置ける（橋もかけられる） |
| 村の範囲 | 配置できる範囲（こちら岸と向こう岸）を**石垣と生け垣**で囲み、地面を少し明るくしている。石垣は川のところだけ切れている。北は根の洞への参道 |
| 町 | **歩くのは主人公（ソラ）だけ**。糸の妖精ツムギが主人公のそばに出るのはダンジョンだけで、武器と重ならない左うしろに浮かぶ。仲間は仕事場のそば（クロベエは炭焼き窯、カイリは水車）にいて話せる。武器はしまって背負う |
| 村のメニュー | 町で Esc / M：ジオラマ配置・武器・持ち物・仲間・村の様子・**セーブ（セーブのあと「ゲームを続けますか？」→ いいえでタイトルへ）**・**ゲーム終了（「セーブしますか？」→ セーブして終了／セーブせずに終了／やめる）**・閉じる |
| 配置／組み立てメニュー | **WASD で操作**（選んでも、マップのカーソルが近くの建物へ勝手に動くことはない）：メニュー操作中は W/S で選ぶ・A/D で左の一覧と右のパーツ欄を行き来・Enter/Space で決定（置くパーツならマップ操作へ）・Esc で町へ。マップ操作中は WASD でカーソル・Enter/Space で置く・Esc でメニューへ。マウスでもできる。左の一覧には建物だけでなく**道・川・橋・木・提灯などもすべて並び**、選んでマップに置く。右の欄は**はめ込みパーツだけ**。置いた建物のカードには「未解放」「k/3」「完成」を表示 |
| ロックオンとカメラ | Q で画面の正面に近い敵をロック／解除、R かホイールで次の敵へ切り替え。ロック中はカメラが敵の方へ向き、離れているほど引いて両方を映す。上に敵の名前と体力。倒すと近くの敵へ自動で移る。ロックしていないときはホイールで寄る／引く、V でカメラを背後へ |
| 階のイベント | **1・2階**：霧の巫女ナギが出口へ続く道の先に現れる／**3階**：ソラしか操作できない／**5階**：中ボス ほつれ蜘蛛（子分を呼ぶ）。倒すと**武器と鍵の入った宝箱**／**7階**：クロベエしか操作できない／**12階**：**QTE だけの階**（敵も宝箱もいない広間）。まん中へ行くと「うつろ」の影が現れて QTE。クリアすると「カイリ」の糸巻きが出て出口が開く。**クリアしたあとはその階に入っても QTE は起きず、そのまま次の階へ行ける**／**14階**：カイリしか操作できない**リミテッド層**（武器の消耗3倍）／**15階**：うつろとのボス戦。7階はクロベエ、14階はカイリが仲間にいないと入れない |
| 15階のボス戦 | うつろ（体力は前の2/3）。広間に4本の**糸の柱**。**柱が1本でも残っているあいだ、うつろには攻撃が効かない**（青い守りの膜・柱からの光る糸・「0」の数字で分かる）。柱は**主人公の攻撃でも、うつろの突進をぶつけても壊せる**（突進でぶつけると3秒目を回す）。4本とも壊すと守りが消え、気絶中はダメージ1.6倍。**18秒たつか体力が1/4減ると、柱が紡ぎなおされて守りが戻る**。画面上に守りの状態（柱の本数／戻るまでの秒数）、柱の上に体力ゲージ。手下は24秒ごとに1体だけ（2体まで） |
| 敵の顔ぶれ（階で固定） | 1階 霧ネズミ／2階 ＋根っこ人形／3階 根っこ人形・胞子／4階 ＋糸喰い蛾（飛び回り2発撃つ）／7階 ＋影法師（2回続けて突進）／9階〜 ＋根の鎧武者（正面からの攻撃を半分受け流す。後ろや横から狙う）。深い階ほど新しい種類が混ざる |
| 仲間 | 最初はソラだけ。洞では仲間は画面に出ず、Tab かメニューで交代 |
| ソラ／クロベエ／カイリ | ソラ：3段コンボ・溜め回転・前転／クロベエ：扇形の薙ぎ払い・旋回防御・穴掘り回避／カイリ：ミシン針・貫く大針・滑る回避 |
| 武器 | 壊れたとき、最初の武器は残って繕い糸で直せる。ほかの武器は消え、アタッチメントは手元に戻る |
| アイテム | 1 薬草／2 灯油／3 研ぎ粉／4 帰り糸／5 繕い糸 |
| セーブ | **メニュー（Esc）の「セーブ」で行う（G キーはなくした）**。洞から戻ったとき・置いた／はめ込んだときは自動セーブ。`save.txt`（テキスト・形式4。**前の形式のセーブは読めない**） |

## 操作
- 町：WASD 移動、Shift ダッシュ、マウス カメラ、E 話す／入る、Tab 配置・はめ込み、**Esc メニュー（セーブもここ）**
- 配置モード：上の表のとおり（WASD・Enter/Space・Esc）。はめ込みパーツを運んでいる間は W/S でカード、A/D で枠、Enter ではめる、Esc でやめる。R 回転、**X/右クリック 1回目＝置いたジオラマを持ち上げて移動（クリック/Enter で移動先に置く・Esc で元の場所へ）、移動中にもう1回＝片付け**（下の表示も「移動」→「片付け」に変わる）、F 建物へカーソル、Q/E 視点、Tab その場所へ移動して町歩き
- 建物の中：WASD 移動、E 話す／買い物／修理／紡ぐ、手前の出口から外へ
- 洞：WASD 移動、Shift ダッシュ、マウス カメラ、左クリック 攻撃、右クリック 技、Space 回避、**Q ロックオン（R・ホイールで切替）**、**V カメラを背後へ**、E 調べる、Tab 交代、1〜5 アイテム、Esc メニュー

## 会話・地図・操作方法
| 項目 | 内容 |
|---|---|
| 会話の話題 | 住人に E で話しかけると話題を選べる。**物語のこと**（ストーリーのヒント）／**ジオラマのこと**（はめ込みの解放と、**その人がはめ込まれている建物の、まだ足りないはめ込みパーツ**を1人1回もらえる。もらったパーツは、まだ開けていない糸巻きのぶんが先に届く形なので、パーツの数はふえない）／**村のこと**（はじめて聞く思い出話で復興率が上がる）／**ちょっとしたコツ**（TIPS）。まだ聞いていない話題には NEW |
| 地図の色 | ジオラマの糸巻き＝黄緑、ふつうの宝箱＝黄色、武器の宝箱＝オレンジ、敵＝赤（ボスは大きく）、泉＝青、階のゴール＝青 |
| ぶつかり | 住人は建物・木・川・ほかの人を通り抜けず、進めなければ別の行き先を選ぶ。主人公も住人や鳥居の柱・石灯籠を通り抜けない。洞では宝箱・糸巻きを通り抜けない |
| 配置メニュー | **建物も道・川・橋・木も**、手持ちを表示（例：×1）。置くと×0になっても左の一覧に残り（うすく表示）、片付けると×1に戻る。×0のときはマップに置く見本を出さない。選んだときだけその行までスクロールし、ホイールで動かした位置は勝手に戻らない。上中央の要望の確認表示はなくした |
| 川と橋のつながり | となり同士に置いた**川は岸がなくなって水がつながる**。**もとの川（地形の川）のとなりに置くと、地形の川の岸もあいてつながる**。**橋を横に並べると欄干が消えて幅広の1本の橋**に、端と端で並べると平らな橋でつながる |
| 橋と井戸の制限 | 橋・井戸は、となり（ななめも）に建物（家・工房・店など）があると置けない |
| 敵の数 | 1部屋に1〜2体で、深い階ほど1体だけの部屋が多い。1つの階で多くても12体（9階から10体） |
| 押しっぱなし | メニューや配置のカーソルで、上下左右（WASD・矢印）を押しっぱなしにすると0.35秒後からくり返し動く |
| タイトル画面 | はじめから・つづきから・**設定**（カメラの感度／画面の揺れ／ダメージの数字／ダンジョンの地図の大きさ。`settings.txt` に保存）・**ゲームを終了する** |
| 操作方法 | 村のメニュー「操作方法」と洞のメニューの「操作」タブで、**ジオラマ配置のとき／町を歩くとき／ダンジョン探索のとき**のページを見られる（村は A/D、洞は W/S でページ切り替え） |
| 木の色 | 村の木はすべて緑（濃い緑と若葉色） |

## そのほか
| 項目 | 内容 |
|---|---|
| 回避 | 動き・硬直は元の長さ（ソラ 0.4秒・クロベエ 0.6秒・カイリ 0.45秒）。**無敵の持続時間を1秒のばし、その1秒のあいだ回避の向きへすべり続けて距離ものびる**（ソラ 2.4m → 約6.5m）。すべっている間も硬直はなく、そのまま動ける・攻撃できる。被弾すると止まる |
| 敵の回りこみ | 敵がこちらのまわりを回りこむ速さを遅くした |
| 数の表示 | 「×数」は**すべてカード・マスの右下**にそろえた（左の一覧・置いた建物のカード・右の欄）。カードの説明は「1×1」などの**大きさだけ** |
| 建物のカード | はめ込みのある建物のカードは、**置く前も置いたあとも同じ形**（左のゲージと「0/3」などの数・建物の絵・名前・はめ込み枠・右下の×数、完成したら「完成」）。道・木・川などのカードは絵・名前・大きさ・×数。置いた建物は、そのカード1枚だけで表す（「0/3」の別カードは出さない） |
| はめ込みは外れない | 一度はめ込んだパーツは取り外せない。**はめ込んだ建物も片付けられ、パーツは建物についたまま手持ちへ戻る**（左のカードもはめ込んだようすのまま）。もう一度置くとパーツごと元どおり。村長の家だけは片付けられず移動のみ |
| 橋の端 | 橋の両端の1マスは通り道なので、井戸や建物は置けない（道は置ける）。建物などがある所に端がかかる橋も置けない |
| ボスを倒したあと | 5階（ほつれ蜘蛛）・15階（うつろ）は、ボスを倒したあとにもう一度来ると**ボスが現れず、何もない層**になる（15階の柱もなし）。出口は最初から開いている。12階の QTE もクリア後は起きない |
| 会話中の敵 | 会話しているあいだ、敵も飛び道具も止まり、攻撃してこない |
