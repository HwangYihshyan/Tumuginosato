# ツムギノサト ― 霧海の記憶 ―（垂直スライス）

C++17 / DirectX 11 / HLSL。企画書 第2版（2026/11/15）の第1章をもとにした試作です。
テクスチャは同梱の KageNui_Textures から必要なものだけ `Assets/Textures` にコピーしています。

## ビルドと起動
```
build.bat                      … bin\TsumugiNoSato.exe ができる
bin\TsumugiNoSato.exe          … 通常プレイ
bin\TsumugiNoSato.exe --autoshot Screenshots   … 自動デモを流してプレイ画面を10枚保存して終了
```

## 入っているもの
| 企画書 | 実装 |
|---|---|
| 4.1 ダンジョン | BSP法の自動生成（30×30マス・部屋4〜6）、5階は固定マップ、鍵持ち→出口の封印、灯ゲージ、ミニマップ、泉・宝箱、結び目、6階/10階の解放条件（復興率30%/60%） |
| 4.2 戦闘 | 3段コンボ、溜め攻撃、ガード、回避（無敵時間）、ロックオン、攻撃トークン（同時に攻撃する敵は最大2体）、ヒットストップ、ダメージ数字、カメラ揺れ |
| 敵 | 霧ネズミ（突進）・根っこ人形（近接）・胞子（遠距離）、中ボス ほつれ蜘蛛。待機→発見→接近→攻撃→後退→被弾→死亡 の状態遷移 |
| 4.3 操作キャラ | ソラ（糸切りばさみ・近距離）／クロベエ（ひも通し・中距離）。Tab で交代、控えはAIで援護しHPが少しずつ回復 |
| 4.4 武器の破損 | 耐久（当てると−1、溜め−3、ガード−1）、25%で黄・10%で赤点滅、0で壊れて予備の道具に、ほつれ糸を回収、経験値で武器Lv |
| 4.5 復興 | 20×20グリッド配置・回転・撤去、住人の要望6種の判定、復興率で霧・空・御神木・住人の数が変わる、町歩き視点 |
| 4.6/4.7 | 薬草・灯油・研ぎ粉・帰り糸、探索画面/復興画面のUI、会話ウィンドウ |

## 操作
- 村：マウス/WASD カーソル、左クリック/Enter 配置、R 回転、右クリック/X 片付け、Z/C 部品選択、Q/E 視点、Tab 町歩き視点、F 根の洞へ
- 洞：WASD 移動、マウス カメラ、左クリック 攻撃（長押しで溜め）、右クリック ガード、Space 回避、Q ロックオン、E 調べる、Tab 交代、1〜4 アイテム、Esc 終了

## まだ入っていないもの
武器の進化・スロット・紡ぎなおし画面、セーブ、物語イベント（8階・章末）、10階ボス（大樹の番人）専用の敵、ゲームパッド、サウンド。
